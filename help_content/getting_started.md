# Як почати роботу з ChessTree

Цей розділ пояснює базовий сценарій користування сайтом без складних кроків. Ідея така: зайти на сайт, знайти потрібний дебют, застосувати фільтри та перейти до детальнішої сторінки дебюту.

## Крок 1. Відкрий головну сторінку

На головній сторінці (Home) є поле пошуку дебютів. Можна:
- вводити назву дебюту вручну;
- вибирати варіант із підказок у списку;
- натиснути Enter або кнопку пошуку.

Після цього сайт перенаправляє у Library до списку дебютів.

## Крок 2. Перейди до Library

Library — основне місце для роботи з дебютами. Тут ти бачиш список карток, де кожна картка відповідає одному дебюту.

Якщо потрібно, можна перейти в Library і через верхнє меню, не використовуючи пошук із головної сторінки.

## Крок 3. Вибери дебют

У Library переглянь назви дебютів і коротку інформацію на картках. Коли знаходиш цікавий варіант, натискай на картку — відкриється окрема сторінка цього дебюту.

## Крок 4. Використай фільтри

Кнопка Filter by відкриває панель фільтрів. Базові дії:
- обрати сторону гри (White або Black);
- обрати тип першого ходу (First move);
- звузити складність (Difficulty);
- виставити діапазон рейтингу (Elo range).

Після застосування фільтрів список оновлюється автоматично.

## Крок 5. Навігація по сайту

Для переходів використовуй верхнє меню:
- Home — повернення на головну;
- Library — повернення до бібліотеки;
- Contact — сторінка контактів.

Розділ Explorer поки що недоступний для роботи (позначений як у розробці).

## Базовий сценарій користувача (коротко)

1. Відкрив сайт.
2. Знайшов дебют через пошук або перейшов у Library.
3. Відфільтрував список за потрібними параметрами.
4. Відкрив картку дебюту.
5. За потреби повернувся до бібліотеки і обрав інший варіант.

Цього достатньо, щоб почати користуватись ChessTree і поступово зібрати для себе зручний набір дебютів.
