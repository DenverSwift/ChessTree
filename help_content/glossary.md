# Глосарій ChessTree

ChessTree — назва вебсайту для перегляду та вибору шахових дебютів.

Opening — шаховий дебют, тобто початкова схема ходів у партії.

Variation — варіація дебюту, окрема гілка розвитку після базових ходів.

Library — сторінка-каталог, де зібрані дебюти у вигляді карток.

Explorer — запланований розділ для аналізу дебютів; зараз у розробці.

Filter — інструмент відбору, який залишає в списку тільки дебюти за заданими умовами.

Search — поле пошуку дебютів за назвою.

Side — параметр сторони, для якої підходить дебют (White або Black).

First move — тип першого ходу в дебюті (наприклад, King's Pawn або Queen's Pawn).

Difficulty — рівень складності дебюту за шкалою від 1 до 5.

Elo — шаховий рейтинг гравця; у Library використовується як рекомендований діапазон.

Elo range — інтервал рейтингу, за яким можна відфільтрувати дебюти.

Popularity — умовна оцінка популярності дебюту (чим вище, тим частіше грають).

Favourites — позначені користувачем улюблені дебюти.

Opening card — картка дебюту в Library з назвою, метаданими та кнопками дій.

Sort by — сортування списку дебютів (наприклад, за популярністю, складністю або Elo).

Reset all — дія для скидання всіх активних фільтрів до початкового стану.
