Глосарій ChessTree

Ці терміни часто використовуються у Library та Getting Started.

ChessTree — назва вебсайту для перегляду та вибору шахових дебютів.
Opening — шаховий дебют, початкова схема ходів у партії.
Variation — варіація дебюту, окрема гілка розвитку.
Library — сторінка-каталог дебютів.
Explorer — запланований розділ для аналізу, зараз у розробці.
Filter — інструмент відбору дебютів за умовами.
Search — поле пошуку дебютів за назвою.
Side — сторона для дебюту: White або Black.
First move — тип першого ходу в дебюті.
Difficulty — рівень складності від 1 до 5.
Elo — шаховий рейтинг гравця.
Elo range — інтервал рейтингу для фільтрації.
Popularity — умовна оцінка популярності дебюту.
Favourites — улюблені дебюти, позначені користувачем.
Opening card — картка дебюту в Library.
Sort by — сортування списку дебютів.
Reset all — скидання активних фільтрів.
