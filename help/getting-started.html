Як почати роботу з ChessTree

Цей розділ пояснює базовий сценарій користування сайтом без складних кроків. Ідея така: зайти на сайт, знайти потрібний дебют, застосувати фільтри та перейти до детальнішої сторінки дебюту.

Крок 1. Відкрий головну сторінку

  • вводь назву дебюту вручну;
  • обирай варіант із підказок;
  • натискай Enter або кнопку пошуку.

Після цього сайт перенаправляє у Library до списку дебютів.

Крок 2. Перейди до Library

Library — основне місце для роботи з дебютами. Тут видно список карток, де кожна картка відповідає одному дебюту.

Можна перейти в Library і через верхнє меню сайту, без пошуку на головній.

Крок 3-5. Вибір, фільтри, навігація

  • відкрий картку дебюту для детальнішого перегляду;
  • використай Filter by: Side, First move, Difficulty, Elo range;
  • для переходів використовуй Home, Library, Contact.

Explorer поки що недоступний (у розробці).

Короткий сценарій

  1. Відкрив сайт.
  2. Знайшов дебют через пошук або Library.
  3. Застосував фільтри.
  4. Відкрив дебют.
  5. Повернувся до бібліотеки за потреби.
